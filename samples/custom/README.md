# Os teus samples de bateria (TR-808)

Coloca aqui os teus samples WAV com estes nomes:

| Ficheiro | Peça |
|---|---|
| `kick.wav` | Bombo |
| `snare.wav` | Caixa |
| `hat.wav` | Hi-hat fechado |
| `hatOpen.wav` | Hi-hat aberto |
| `clap.wav` | Palmas |
| `tomLow.wav` | Tom grave |
| `tomMid.wav` | Tom médio |
| `tomHigh.wav` | Tom agudo |

Depois de fazer commit e push, escolhe o som **"TR-808 (meus samples)"** na voz drums de um comando na aplicação.

Só precisas dos ficheiros que quiseres usar — as peças em falta usam o fallback sintetizado.

Nota: por uma questão de licenças, usa aqui apenas samples que possas redistribuir.
